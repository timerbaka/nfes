# Webové práce z kurzů (2021–2022)

Sbírka mých prvních prací z HTML, CSS a JavaScriptu. Vznikly během kurzů v Počítačovém centru pro děti a mládež při Univerzitě ITMO (Sankt-Peterburg) a dalších kurzů. Úkoly se odevzdávaly přes výukovou platformu [nfes.ru](https://nfes.ru).

Původně šlo o pět samostatných repozitářů. Spojil jsem je do jednoho, aby byl můj GitHub přehlednější. Historie commitů (autor, datum, popis) je zachovaná.

## Obsah

| Složka | Kdy | Co to je |
| --- | --- | --- |
| [`nfes-html-test/`](nfes-html-test/) | listopad 2021 | Závěrečný úkol ze základů HTML: tři propojené stránky (kočky a psi) s tabulkami, seznamy, obrázky a faviconou. |
| [`nfes_homeworks/`](nfes_homeworks/) | leden 2022 | Domácí úkoly z kurzu (lekce 14: stránka podle zadání, CSS). |
| [`Nfes-N-Final/`](Nfes-N-Final/) | květen 2022 | Závěrečný projekt: web fiktivní firmy pro IT podporu (úvodní stránka a stránka se službami) s vlastním CSS a vertikální šablonou. |
| [`Barbershop/`](Barbershop/) | květen 2022 | Stránka barbershopu podle grafického návrhu, první práce s CSS frameworkem Tailwind CSS. Postup a obtíže jsou popsané v [README](Barbershop/README.md). |
| [`Innovation-cloud/`](Innovation-cloud/) | květen–červen 2022 | Jednostránkový web „Innovation Cloud“ v Tailwind CSS. |

## Kurzy

V Počítačovém centru pro děti a mládež při Univerzitě ITMO jsem absolvoval tři 96hodinové kurzy s nejlepším hodnocením:

- „Úvod do počítačového softwaru a hardwaru“ (2021)
- „Úvod do kancelářských aplikací a internetu“ (2021)
- „Sítě a webdesign (HTML, CSS, JavaScript)“ (2022)

> Zadání úkolů a komentáře v kódu jsou v ruštině, protože kurzy probíhaly v Rusku.
